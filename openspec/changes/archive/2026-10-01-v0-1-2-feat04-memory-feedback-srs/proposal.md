## Why

记忆反馈模式当前的调度是"feedbackSet 二元集合"：点「认识」加入集合，「不认识」/超时不加入，未反馈词在本 Section 内无限轮次重试。该模型存在四个结构性问题：

1. **无限卡死**：用户对一个词反复点「不认识」，该词永远不通过，Section 永远不完成，用户被单卡困住
2. **超时与不认识无区分**：停留超时和明确点「不认识」都被记为"未反馈"，掌握度信息丢失（超时很多时候是"似曾相识但没反应过来"，与完全陌生不是一回事）
3. **反馈数据用完即弃**：feedbackSet 仅存于会话内存，本次背了什么、哪些词薄弱，跨会话全部归零；背记系统没有记忆
4. **完成语义分歧未收口**：PRD v0.1（L53、L242-244）定义完成 = 每词点过一次「认识/不认识」任一反馈（不认识当轮放过）；实现与 spec 是"全部标记认识才完成"（不认识无限重试）。两套语义长期并存，本次必须一并收口

用户已决策采用**分级反馈 + 简易 SRS**方向（C），并拍板以下几项子决策：

- **C2 一步到位**：SRS 调度直接上"全局复习队列"（掌握度到期的词优先，跨 Section），不保留 Section 内 SRS 的过渡形态
- **✗ 改为 ↺ = 「模糊」**：悬浮窗保持 4 键（♡ ▶ ✓ ↺）不变（不改按键数量、不新增按钮），原「不认识」键的图标由 ✗ 换成 ↺ 且语义改为「模糊」
- **超时 = 不认识**：停留超时未操作时自动记为「不认识」（非「模糊」）——被动超时视为"不会"，比主动点「模糊」掌握度更低
- **独立 ReviewState 实体**：掌握度存独立 Core Data 实体，不在 WordEntry 上加字段
- **最大曝光次数可配置**：设置页新增"放行阈值"设置项
- **记忆反馈卡补充两参数**（缓解"单参数卡过薄"）：会话复习上限 `sessionReviewCap`（0-200，0=不限，默认 0，会话级到期复习预算，随进度持久化）+ 复习基础间隔 `reviewBaseIntervalDays`（0.5/1/2 天，默认 1，作用于认识间隔）；走马灯卡保持一行不补参
- **预算随进度持久化**：记忆反馈进度 formatVersion 升至 v2，新增 `reviewBudgetRemaining: Int?`，中断恢复后按剩余预算继续

## What Changes

### 1. 三态分级反馈

记忆反馈模式的反馈从二元（已反馈/未反馈）升级为三态：

- 「认识」（用户点击 ✓）：本会话通过，SRS 升盒
- 「模糊」（用户点击 ↺，原 ✗ 键改图标与语义）：本会话延迟重现（延迟 2 词，比不认识更快再出），SRS 盒级不变
- 「不认识」（停留超时未操作时自动记录，无独立按键）：本会话延迟重现（延迟 3 词，较久），SRS 回盒 1

每次反馈即时写入 ReviewState，掌握度跨会话留存。

### 2. 全局复习队列（SRS 调度主体）

记忆反馈模式的调度主体从"Section 流转"改为"全局复习队列"：

- **到期优先**：ReviewState 到期（dueAt ≤ 当前）的复习词优先进入队列（按 dueAt 升序）
- **新词分批**：无 ReviewState 记录的词条视为新词，按 Section 组织、按「Section 词数」分批补充进队列（Section 语义弱化为"新词分批"，仅记忆反馈模式弱化；走马灯模式保持 Section 流转不变）
- **批次完成** = 批内全部单词「认识」或全部达到"单词最大曝光次数"放行阈值；不再存在无限重试
- **全队列完成** = 无新词 + 无到期复习词时进入"已学完"

### 3. ReviewState 实体（Core Data）

新增独立实体持久化单词掌握度：wordId（唯一）、Leitner 盒级（1-5）、到期时间、最近反馈、累计曝光。轻量迁移加表。反馈即落盘，重启后按 dueAt 重建复习队列。

### 4. 设置项：单词最大曝光次数（固定分区组织）

背记规则设置 Tab 采**固定分区**承载模式专属参数：公共"Section 设置"卡只留 Section 词数 / Section 顺序 / Section 内展示顺序；"走马灯循环轮次"与记忆反馈专属参数各自独立成卡、固定展示，非当前模式整卡禁用 + 半透明。记忆反馈卡承载三行：单词最大曝光次数（1-10，默认 3）、会话复习上限（0-200，0 显示"不限"，默认 0）、复习基础间隔（0.5/1/2 天，默认 1）。"单词最大曝光次数"：单词本会话累计展示达到阈值仍未标记「认识」时放行（本会话不再重现，视同完成当前批次），根治无限卡死。"会话复习上限"：单次会话纳入调度的到期复习词预算，0 不限，随进度持久化。"复习基础间隔"：仅作用于认识间隔（base × 2^(盒-1)）。

### 5. 进度持久化格式升级

记忆反馈模式进度改存新格式（批次词单 + 会话状态 + 曝光计数 + 会话复习剩余预算，formatVersion 升至 v2）；旧格式进度一次性失效清零（沿用既有"旧版本索引寻址失效"先例）。走马灯模式进度格式不变。

### 6. PRD 完成语义收口

以本次 spec 为准：批次完成 = 批内全部「认识」或达曝光阈值放行（取代 PRD 的"每词点过任一反馈"与实现的"无限重试到认识"两套旧语义）。PRD 文档更新列为收尾任务，由用户验证时人工确认。

### 7. 「重新开始」与「重置学习记录」双入口（用户已拍板）

掌握度积累后，"重新开始"的语义需要拆分：

- **重新开始**（既有入口）：仅重排本会话，**保留** ReviewState 掌握度——适合换顺序、换脑子，误触不毁数据
- **重置学习记录**（新增入口，仅记忆反馈模式"已学完"状态展示）：确认对话框后清除全部 ReviewState，所有词条回到新词状态——彻底重来的唯一入口，防误触

入口位于悬浮窗右键菜单"已学完"状态顶部区域（重新开始 → 重置学习记录 → 打开设置 → 退出程序）；走马灯模式"已学完"不展示"重置学习记录"（走马灯无掌握度数据）。

## Capabilities

### New Capabilities

无（扩展现有能力）。

### Modified Capabilities

- `recite-engine` — 核心重写：记忆反馈模式三态分级反馈、全局复习队列调度（新增 2 个 Requirement）、曝光阈值放行（新增 1 个 Requirement）、重置学习记录（新增 1 个 Requirement）、Section 队列构建/首词展示/组内顺序/续背循环/全队列完成/进度持久化 6 个 Requirement 按"走马灯保留 + 记忆反馈新语义"收窄重写
- `core-data` — 新增 ReviewState 实体持久化 Requirement
- `settings-window` — 背记规则 Tab 改固定分区：卡片自上而下按序为 Section 设置（公共）→ 背记模式 → 走马灯 → 记忆反馈；公共"Section 设置"卡移除走马灯循环轮次行，新增"走马灯"与"记忆反馈"两模式专属卡片（非当前模式整卡禁用 + 半透明），记忆反馈卡承载三行（曝光次数 / 会话复习上限 / 复习基础间隔）
- `floating-window` — 右键菜单"已学完"状态新增"重置学习记录"项（带确认对话框），"重新开始"语义明确为保留掌握度

不涉及：`ui-localization`（机制不变，仅新增词条，在 tasks 中处理）、`terminology`（"批次"仅出现在 spec 与代码注释，UI 不暴露，不入术语表）。

**兼容性：**

- 走马灯模式全部既有行为与 Scenario 不变（Section 流转、循环轮次、续背锚点、进度格式）
- 悬停暂停、用户暂停、静音挂起、通知响应等横切能力不变，仅记忆反馈调度分支重写
- ReviewState 为新增表，轻量迁移自动完成；旧进度数据失效清零为一次性代价（先例一致）
- 旧版本升级后 `maxExposureRounds` / `sessionReviewCap` / `reviewBaseIntervalDays` 缺失均按默认值处理（StoredSettings 可选字段）

**已知取舍：**

- 词库重新导入后 wordId 全部更新，既有 ReviewState 变为孤儿记录（不参与调度、不主动清理）——语义即"重导入 = 重置学习记录"，数据量每词一条可忽略
- 超时被动记为「不认识」（最重处置，回盒 1）：用户分心导致的超时会被判为"不会"。属设计意图（用户拍板"超时 = 不认识"），曝光阈值兜底避免卡死；明确有印象但没反应过来时，主动点「模糊」（↺）即可获得温和处置
- delegate 协议保持不变：记忆反馈模式下"批次完成"复用 `engineDidCompleteSection`（批次序号作 sectionIndex），悬浮窗既有消费方（空实现）无感
- "已学完"展示期间 ReviewState 陆续到期不唤醒调度（无到期轮询），下次引擎启动（重启应用 / 重新开始）才复习到期词

**已确认决策（2026-10-01 用户拍板）：**

- 「重新开始」保留 ReviewState 掌握度（仅重排会话）；清除掌握度走新增的「重置学习记录」独立入口（仅"已学完"状态展示，带确认对话框）
- 「模糊」按钮符号用 ↺（原 ✗ 键改图标与语义）；「不认识」无独立按键，停留超时自动记录
- 会话内重试节奏：不认识（超时）延迟 3 词重现、模糊（↺）延迟 2 词重现（Constants 常数，实施后可调）
- SRS 间隔：认识 1 天 × 2^(盒-1)（1/2/4/8/16 天）、模糊 4 小时、不认识 1 小时（Constants 常数，实施后可调）
